# 1142949 HW06｜京都百鬼夜行：陰陽鎮魂對弈

陳辰瑋 · 1142949 · Tic-Tac-Toe Web 版

## 開啟與操作

解壓縮後，用 Chrome 或 Edge 開啟 `index.html`，按「開始《伏見血月》」。原畫、配音與遊戲程式都隨附在專案中。片頭依語音和字幕播放進度自動切幕。用滑鼠點空格，或用 Tab 選格後按 Enter。金紅御守是玩家，青色狐印是電腦。

玩家先手，電腦後手。九印皆落下後才結算。橫、直或斜的三連線各計一分，線數較多者獲勝。同分且雙方都有成線時，由先成線者獲勝。雙方皆未成線則和局。首次三連會立刻畫出該方的一條線，接著繼續落子。滿盤時重新結算，終局只留勝方的一條直線。結尾播放完會回到終局棋盤，並顯示「再戰一局」和「回主選單」。

### 替補池（補足每手兩招，並取代重複的招式）

某一手的奧義不到兩招時，或狐眼、水墨「封」、天雷在同一局要第二次出現時，會依序改播下面還沒出現過的招式：

所有 945 種下法中，一局最多需要從替補池補 10 次，替補池剛好 10 招，所以任何下法都能做到「每手兩招、整局不重複」。

電腦每次一般落子時，會有一隻由上百團狐火組成的九尾妖狐靈體從右側角色區全速撲進落子格，九條火尾拖過舞台，最後炸成九團狐火。最後一手落下前改播「九星天命陣」：雙層金環環繞棋盤、九根光柱升起，九顆天星盤旋後一顆顆墜入落子格。

v15 精修：乾坤翻面（神光放射、翻轉殘影、背面陰陽鏡刻八卦字、邊緣火花與落地重擊）、鬼神巨口（立體牙齒與牙齦、口水絲、充血巨眼、咬合衝擊波）、虛空黑洞（重力透鏡扭曲星空、都卜勒增亮的吸積盤、繞到上方的光弧）、羅生門（木紋漆門、鬼瓦、門匾、透視開門、湧出的百鬼魂靈）。

奧義會跟著右上角的三段畫質（極致／流暢簡化／無 GPU 相容）自動減少粒子；播放中若掉幀也會再降一級。系統設定「減少動態效果」時，改成短暫的光暈版本。

### 勝負畫面

每回合結束，終局奧義播完後會先跳出 3 秒的大字勝負畫面（「玉藻前 獲勝／你 獲勝！／和局」、勝敗印章、雙方連線數與勝負原因），再播結局動畫；動畫結束後勝負畫面會再出現並停留，附「再戰一局／查看棋盤／回主選單」按鈕。

## 驗收走法

棋盤由左上到右下編為 1–9。表內只列玩家要按的格子，電腦會自行應對。

| 玩家依序點 | 可看到的結果 |
| --- | --- |
| 1 → 2 → 7 → 8 → 9 | 每手兩招以上、整局 21 招不重複，結尾天照日輪 → 碎裂重組 → 勝負畫面「玉藻前 獲勝」。滿盤兩方各一線，線數相同，電腦先成線所以電腦勝。 |
| 1 → 2 → 7 → 6 → 8 | 九子落滿、雙方皆未成線，和局，終局播放太極大漩渦。 |
| 5 → 2 → 4 → 3 → 9 | 最吃替補的下法：替補池 10 招全部出現，整局 22 招不重複，和局。 |

Minimax 完整推演至九印全滿，用快取重複盤面。v10 交付前用 Node 依遊戲實際使用的電腦策略，窮舉所有玩家合法落子：共 945 條終局路徑，電腦勝 834 局、和局 111 局、玩家勝 0 局（玩家勝率 0.00%）。並在 Chrome 開啟 GPU 與關閉 GPU 兩種模式各跑完上面兩條走法，全部奧義都有播出、同一局沒有重複、0 個錯誤。

## 配音

台詞統一放在 `js/voice-lines.js`。v10～v12 改寫了 22 句台詞（例如「桔梗結界，立！」→「護身結界，展開！」、「第一印，鎮！」→「第一道靈符，結界成形！」），舊音檔是用舊台詞錄的，遊戲會自動偵測：台詞和音檔對不上的句子先改用瀏覽器內建中文語音念新台詞（Windows 的 Chrome／Edge 會用同一組 Microsoft 男聲、女聲），字幕與聲音不會錯開。

要換回隨遊戲打包的音檔：在 Windows 電腦上雙擊 `tools/make_voices.bat`。工具會直接讀 `js/voice-lines.js` 重新產生全部語音與 `assets/voice/manifest.js`；電腦上若有 Python（含 numpy）與 ffmpeg，會再自動套用 `tools/voice_direct.py` 的語氣後製。完成後重新整理網頁即可，`assets/voice/_raw` 資料夾可刪除。
