## 電腦為什麼不會輸

程式裡 `// <AI>` 到 `// </AI>` 之間就是 AI：

- **Minimax 完整搜尋**：每一步都把剩下的棋局全部算完。
- **分數含步數**：越快贏分數越高，所以會選最快的勝法。
- **記憶化**：算過的盤面存起來，不會重算。
- **陷阱優先**：有好幾步一樣好時，挑「讓你下一手最容易走錯」的，再隨機選，所以每局都不一樣。

已用程式窮舉驗證：玩家所有走法 × 電腦每一種可能選擇，共 1408 局，**電腦 0 敗**（1008 勝、400 和）。

## 技術摘要

- 單一 HTML 檔（加上同資料夾的 bgm.mp3），自寫 WebGL2 引擎：場景樹、Blinn-Phong＋半球光＋12 盞點光源、PCF 陰影、粒子系統、ACES 色調映射、桌面水面倒影（stencil）、燈籠投影
- 盤龍用程式產生螺旋管狀網格；燈籠串、龍首、龍爪等小零件合併成單一網格，減少繪製次數
- 角色手臂、視線、冕旒珠串都即時計算；表情用動態產生的臉部貼圖切換
- 河面倒影：每顆煙火火花會算出它對水面的鏡像點與視線的交點，在河面畫出倒影
- 字形煙火：把文字畫在畫布上取樣成點陣，火花從爆炸中心飛到各點後停留閃爍
- 導航：場景三角形投影到 8 公分格子，朝上的面決定地面高度，水平切面判斷障礙，距離轉換得到離障距離；角色半徑以下的格子不可走
- 不支援 WebGL2 的電腦會自動改用平面棋盤，規則與 AI 相同
